# Software Architecture & Design Patterns Practicals

A structured collection of Java and Spring Boot practical assignments for M.Sc. Computer Science Part II, Semester III, Academic Year 2026–2027.

## Objectives

- Understand SOLID principles and MVC architecture.
- Implement creational, structural, and behavioral design patterns.
- Build applications using the Spring Framework.
- Explore microservices architecture with Spring Boot and Spring Cloud.
- Practice clean code, testing, documentation, and software design.
